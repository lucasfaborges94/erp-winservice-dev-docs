# ADR-0003 — WeWeb como aplicação administrativa web

**Estado:** APROVADA

## 1. Contexto

O projeto prevê uma aplicação web para administração e operação do ERP. O mapa de stack identifica WeWeb como a direção para essa interface e registra hospedagem na VPS. A topologia final da infraestrutura, os contratos de API e o desenho completo de autenticação ainda precisam ser detalhados.

O registro primário da deliberação original, sua data e os participantes não estão documentados. Esta ficha individualiza uma decisão que consta como aprovada no baseline do índice de decisões.

## 2. Problema ou necessidade

Definir a tecnologia de referência para a aplicação administrativa web e sua diretriz de hospedagem.

## 4. Decisão

WeWeb será utilizado como tecnologia da aplicação administrativa web do ERP, hospedada na VPS.

Esta decisão define a tecnologia e a diretriz de hospedagem. Não define topologia final, estratégia de deploy, ambientes, autenticação, autorização, APIs, observabilidade ou escalabilidade.

**Estado de aprovação:** preservado como APROVADA, conforme o baseline legado registrado em documentacao/02_DECISOES_ARQUITETURA.md. A data e o registro primário da aprovação original permanecem não documentados.

## 6. Consequências e impactos

### Benefícios esperados

A interface administrativa será construída em WeWeb e deverá consumir os serviços e dados segundo a arquitetura central do ERP. A interface não será a camada exclusiva de segurança; autorização deverá ser aplicada no backend e no banco. Não manter cache operacional local como fonte alternativa dos dados.
